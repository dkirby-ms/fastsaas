# FIDO Decision Inbox — #158 Plan Archive UI

- Date: 2026-06-08T13:22:40Z
- Requested by: dkirby-ms

## Decisions
1. Publisher plans now use a simple `active` / `archived` status model in the portal UI, matching the project decision to avoid a separate disabled state.
2. Archived plans are shown in a separate collapsible section so the active catalog stays focused while still making restore actions easy to find.
3. Plan status is managed from the list-level Archive / Restore actions instead of the edit form; new plans default to active.
